### 🏗️ Featured Architecture: SAMA Open Banking Ecosystem
* **[Fath | فتح — Saudi Open Banking Sandbox (ASPSP/TSP)](https://github.com/yamen-alwaily/fath):** Simulates SAMA AIS & PIS standards across 3 Saudi banks with pure-Python **OAuth 2.0 + PKCE (`RFC 7636`)**, **ISO 13616 MOD-97** Saudi IBAN validation, and real-time **SocketIO** payment state streaming.
* **[Smart Wealth | الذكاء المالي — AI Fintech & AISP Client](https://github.com/yamen-alwaily/smart-wealth):** Connects to `Fath` over Docker via OAuth 2.0 PKCE to automate idempotent transaction syncing into a dual-engine **PostgreSQL 16 / SQLite** database layer, featuring a 4-pillar Shariah credit scoring engine and localized **Z-score** anomaly detection.
